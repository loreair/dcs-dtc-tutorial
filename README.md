# 🎮 DCS: Tutorial DTC (Data Transfer Cartridge)

Benvenuto nella serie di tutorial dedicati all'uso delle **DTC (Data Transfer Cartridge)** in DCS World.  
Qui troverai i file `.dtc` da scaricare per ogni velivolo, da usare insieme ai video tutorial per comprendere al meglio le procedure.

---

## 📺 Cos'è questa serie?

Questa serie di videotutorial ti guiderà passo-passo nell'utilizzo delle **Data Transfer Cartridge** nei vari moduli di DCS World.  
Ogni video è accompagnato da un file `.dtc` pronto per essere scaricato e utilizzato nella tua installazione di DCS.

**Come funziona:**
1. Scarica il file `.dtc` del velivolo che ti interessa
2. Copialo nella cartella DTC di DCS World (vedi istruzioni sotto)
3. Segui il video tutorial corrispondente
4. Metti in pratica ciò che hai imparato!

## 📥 Come Installare i File .dtc

### Percorso di installazione:

Copia i file `.dtc` scaricati in questa cartella:

```
C:\Utente\Saved Games\DCS\DTC
```

### Procedura passo-passo:

1. **Scarica** il pacchetto ZIP del velivolo dal link corrispondente
2. **Estrai** il file `.dtc` contenuto nell'archivio ZIP
3. **Copia** il file `.dtc` nella cartella:
   ```
   C:\Utente\Saved Games\DCS\DTC
   ```
4. **Avvia** DCS World
5. **Carica** la DTC dal menu dell'aeromobile corrispondente
6. **Segui** il video tutorial per comprendere le impostazioni
