## 📥 Installazione

1. Scarica il pacchetto ZIP del velivolo dal repository.
2. Estrai il file `.dtc` contenuto nell'archivio ZIP.
3. Copia il file `.dtc` nella cartella:

   `C:\Utente\Saved Games\DCS\DTC`

4. Avvia DCS World.
5. Carica la DTC dall'interfaccia del velivolo corrispondente.
6. Segui il videotutorial associato per comprendere le impostazioni e le procedure.

## 📋 Requisiti

- DCS World
- Modulo corrispondente al velivolo (es. DCS: F/A-18C)
